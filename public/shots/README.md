# Product Tour screenshots (drop-in)

The Product Tour shows polished **mockups** by default. To replace any panel with a
**real screenshot** of TestOps Hub, just drop a PNG here with the exact name — it
appears automatically, no code change:

| File name              | Panel it replaces        | What to capture |
|------------------------|--------------------------|-----------------|
| `cortex.png`           | Cortex · ask             | A Cortex question + its cited answer |
| `test-studio.png`      | Test Studio · scenarios  | A project's scenario table |
| `decision-table.png`   | Decision Table           | A built decision table |
| `delivery-board.png`   | Delivery Board · flow     | The delivery board columns |

Tips for clean shots:
- Crop out the app sidebar and the yellow "dev auth" banner — capture just the panel.
- Landscape, roughly 3:2 or 16:10, ~1400px wide looks best in the frame.
- If a file is missing or fails to load, the mockup is shown instead (safe fallback).
